# 게임 리그오브레전드의 루시안 딜량 계산기 (LoL Lucian Damage Calculator)

## 프로젝트 목적과 대상: 사용자
리그 오브 레전드 챔피언 '루시안'의 딜량을 레벨, 아이템, 룬, 상대 챔피언 조건에 따라 계산하고 시각화하는 웹 애플리케이션입니다. 실제 게임의 딜 계산 공식(방어력 감쇄, 치명타 확률/피해량, 스킬 쿨타임 등)을 기반으로, 빌드나 룬 선택에 따른 딜량 변화를 사전에 비교해보고 싶은 루시안 유저 또는 롤 딜량 계산 원리에 관심 있는 사람을 대상으로 합니다.

## 실행 방법
```bash
git clone <repository-url>
cd lol-lucian-stats-dashboard
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app/main.py
```
실행 후 브라우저에서 `http://localhost:8501` 접속.

## 작업 과정 요약
1. Streamlit 기반 프로젝트 뼈대 구성 (폴더 구조, .gitignore, requirements.txt)
2. 챔피언/아이템/룬 데이터 스키마 설계 및 예시 데이터 작성
3. 방어력 감쇄 공식(100/(100+방어력))을 적용한 기본 데미지 계산 로직 구현
4. 상대 챔피언 레벨을 아이템 개수 기준으로 자동 추정하는 기능 추가 (수동 조정 옵션 포함)
5. 직접 고안한 스킬 콤보 계산 기능 추가 — 5초간 지속되는 상황을 위한 DPS 콤보(E-평-Q-평-W-평 후 스킬 쿨타임마다 평타 사이 스킬 삽입)와, 한 번에 몰아치는 폭딜 콤보(E-평-Q-평-W-평-R-평) 두 종류 구현
6. 치명타 계산을 기댓값(치명타 확률 기반 평균) 방식으로 반영, 무한의 대검 착용 시 치명타 피해량 보너스(+30%p) 및 루시안 궁극기의 치명타 확률 비례 발사 횟수 증가 반영
7. 실제 룬 페이지 구조(메인룬: 정밀/지배/마법/영감, 부룬: 정밀/지배/영감)를 재현하되, 원거리 딜러 실전 채용률이 높은 룬 위주로 목록을 선별해 범위를 관리 가능한 수준으로 제한
8. 단계마다 Claude Code로 기능 구현 → 로컬 환경에서 직접 실행/테스트 → 문제 발견 시 수정 요청 → 커밋, 순서로 반복 진행

## 선별된 Claude Code 증거 및 검증 결과
- 단위 테스트 총 40개 작성, 전체 통과 확인 (`pytest` 실행 결과)
- 방어력 감쇄 공식은 방어력이 음수인 엣지 케이스까지 포함해 테스트 (실제 롤에서도 방어력 디버프로 음수가 가능한 상황을 반영)
- Streamlit 앱을 로컬에서 직접 실행하여, 레벨/아이템/룬/상대 조건을 바꿔가며 계산 결과가 조건 변화에 맞게 달라지는지 수동으로 검증 (예: 아이템 개수를 늘렸을 때 데미지가 함께 증가하는지 확인)
- import 구조 오류(`ModuleNotFoundError`) 발생 시 Claude Code가 원인을 분석하고 수정한 뒤, 별도 환경에서 재실행하여 수정을 독립적으로 재검증

## 효과적이었던 작업 방식 3가지
1. 작업을 단계별로 쪼개서 요청: 한 번에 전체 기능을 요청하기보다 작은 단위로 나눠 요청할 때, 의도에 더 정확히 맞는 결과와 높은 완성도를 얻을 수 있었다.
2. 추상적 표현을 구체적 수치로 변환: '세다', '빠르다' 같은 게임 관련 표현을 그대로 쓰지 않고, 실제 수치(치명타 배율, 레벨-아이템 매핑 기준 등)로 구체화해서 요청했을 때 의도에 맞는 결과가 나왔다.
3. 모르는 개념은 그때그때 설명을 요청해 이해하고 넘어감: 작업 중 낯선 개념이 나올 때마다 명확한 설명을 요청하고 이해한 뒤 다음 단계로 넘어가는 방식이, 이후 작업이 막히는 것을 방지했다.

## 겪은 어려움 3가지
1. 터미널 환경 자체가 낯설었음: 명령어 입력, 텍스트 에디터(nano) 사용 등이 익숙하지 않아 중간중간 막혔고, 검색과 질문을 통해 하나씩 해결했다.
2. 요청 범위가 넓으면 에이전트가 임의로 판단해 진행하는 경우가 잦았음: 구어적 표현 대신 의도를 명확하고 구체적으로 명시했을 때 이 문제가 해결됐다.
3. 저작권 등의 이유로 실제 게임 데이터를 그대로 가져오기 어려웠음: 일부 수치는 공식 자료를 직접 찾아 확인하거나, 게임을 실행해 직접 값을 입력하는 방식으로 해결했다.

## 알려진 한계점
- 상대 챔피언의 레벨은 실제 경기 데이터가 아니라, 아이템 개수 기준의 근사 매핑(가정값)으로 추정되며 실제 게임 진행과 다를 수 있다.
- 치명타는 실시간 난수(RNG) 시뮬레이션이 아닌 확률 기반 기댓값(평균)으로 계산되어, 실제 한 판의 결과와는 차이가 있을 수 있다.
- 룬은 전체 트리가 아닌 원거리 딜러 실전 채용률이 높은 일부만 구현되어 있다.
- 스킬 시전 시간, 투사체 이동 시간은 0으로 단순화되어 있다.
